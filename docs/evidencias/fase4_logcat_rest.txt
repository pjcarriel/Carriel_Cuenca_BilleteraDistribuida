TRES HILOS DISTINTOS EN CADA OPERACIÓN:
  main                         -> ViewModel (clic y actualización de la UI)
  DefaultDispatcher-worker-N   -> Repository (withContext(Dispatchers.IO): Room y llamada a Retrofit)
  OkHttp http://10.0.2.2:8090  -> hilo propio de OkHttp que hace la E/S de red
Ninguna operación de red ni de base de datos se ejecutó en main.

PROBLEMAS ENCONTRADOS Y SOLUCIÓN
1) Android 17 (API 37) bloquea las conexiones de las apps a la red local (10.0.2.2) si no tienen el
   permiso peligroso android.permission.ACCESS_LOCAL_NETWORK -> "SocketTimeoutException: failed to connect".
   Solución: declararlo en el Manifest y pedirlo en tiempo de ejecución (fase4_permiso_red_local.png).
2) El motor Netty de Ktor no respondía a las conexiones que llegan desde el emulador en esta PC (Windows),
   aunque sí a las de la propia PC; un servidor Java mínimo y uno Python sí respondían.
   Solución: cambiar el motor de Ktor a CIO (Coroutine I/O). El puerto pasó de 8080 a 8090.
